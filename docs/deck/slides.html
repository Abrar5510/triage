What Triage does

Models propose. Sandboxes execute. Rules decide.

01 · LLM

Intake

Flags prompt injection aimed at the agent
02 · LLM

Extract

Package, versions, function, impact, PoC
03 · CODE

Ground

Exact version from PyPI. Does the function exist?
04 · SANDBOX

Submitted PoC

Reporter's code, contained, watched
05 · LLM + SANDBOX

Reproduce

Agent writes a test, runs, retries on errors
06 · SANDBOX

Control

Same test on the patched version
07 · RULES

Decide

Verdict from evidence, never from the model
Reproduced

Vulnerable on affected, clean on patched

Not reproduced

Grounding failed or behavior never appeared

Hostile

Submitted PoC triggered a policy event

Inconclusive

Escalated to a human with all evidence

Built on Vultr

The VM is the control layer. Inference is the brain.

Vultr Cloud Compute

One VM runs it all

FastAPI web app with a live SSE timeline, the agent orchestrator, the hash-verified package cache, and the Docker + gVisor sandbox runtime, behind Caddy with automatic HTTPS. One setup script.

Vultr Serverless Inference

Every LLM call

Intake screening, claim extraction, reproduction-test writing, retry reasoning and the reviewer note, through the OpenAI-compatible API. Fast, smart and safety model roles, each one env var.

The orchestrator holds the only API key. Sandboxes never see it, and they have no route to use it anyway.
