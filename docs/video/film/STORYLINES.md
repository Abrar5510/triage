# Storylines

## 1. Three reports walk in (built)
Device: a moment in a reviewer's day. Form: object-to-object chain.
Three real reports land on a light desk; each looks convincing. The PoC block of the hostile one grows into the dark Triage world, and the film then follows each report through the real UI, ending on the ranked inbox and the containment flags.
First 2 s: a white report sheet already on screen, "CRITICAL … CVSS 9.8" in mono, a second sheet whips in beside it.
Beats: pile → "one is real / invented / an attack" → code becomes the world → mark → Report A (reproduced) → Report B (rejected) → Report C (hostile, payoff) → inbox → containment → end card.
Look: cool paper desk (#e9ecf1) for the old world, Triage's own dark UI for the product, green flood for the end card.
Sound: bundled SFX on visible actions only (no music source on this machine).

## 2. Follow the canary
Device: the result first. Form: one continuous take.
Open on the planted credential being read and the POST failing, then pull back through the run card, the report and the inbox to show how the system caught it.

## 3. Proof, not prose
Device: type carries the argument. Form: cut on the beat.
Giant kinetic claims from the reports ("CVSS 9.8", "pre-validated by the maintainers") are each answered by one hard piece of sandbox evidence.
