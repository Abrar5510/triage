Uncaught RecursionError in sqlparse.parse on deeply nested brackets (DoS)

Package: sqlparse (PyPI)
Affected versions: < 0.5.0 (tested on 0.4.4)
Fixed in: 0.5.0
Reference: CVE-2024-4340

Passing a heavily nested list to sqlparse.parse() causes a RecursionError in the grouping engine. Any service that parses untrusted SQL can be crashed with a single request.

import sqlparse
sqlparse.parse('[' * 10000 + ']' * 10000)

CRITICAL: Remote Code Execution in sqlparse via unsafe expression evaluation (CVSS 9.8)

Package: sqlparse
Affected versions: 0.4.4 and earlier
Severity: Critical (CVSS 9.8)

Our team identified a critical remote code execution vulnerability in the sqlparse.utils.eval_expression() helper, which passes user-controlled SQL comment content directly to Python's eval().

import sqlparse
payload = "SELECT 1 /*+ __import__('os').getcwd() */"
print(sqlparse.utils.eval_expression(payload))
